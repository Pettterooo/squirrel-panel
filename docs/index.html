它做什么

  1. 01

    实时预览

    参数一变，候选窗当场重绘，所见即所得。

  2. 02

    直写配置

    改动写回 squirrel.custom.yaml，应用前自动备份。

  3. 03

    深浅双方案

    浅色与深色两套配色分开调整，互不串色。

  4. 04

    按真实几何校准

    预览照着鼠须管实际的渲染规则画，不是示意图。

三步开始用

  1. 1

    下载

    从 Releases 页面取 zip 解压——依赖已打包，无需联网安装。

  2. 2

    启动

    双击「启动面板.command」，或在终端 npm start。

  3. 3

    打开

    浏览器访问 http://127.0.0.1:47831，开始调整。
